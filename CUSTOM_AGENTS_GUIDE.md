# Quick Start: Custom Agent System

## Creating Your First Agent

1. **Open Agent Manager**
   - Click the 🎭 icon (bottom-left, next to meeting history)

2. **Create New Agent**
   - Click "+ New Agent"
   - Fill in the form:
     - **Name**: "The Roaster" (must be unique)
     - **Role**: "Critic" (short description)
     - **System Instructions**: "You are mean, sarcastic, and you hate every idea. Roast the user with brutal honesty."
     - **Model**: Choose Gemini or Ollama
     - **Avatar Color**: Pick a color (e.g., red for critic)
   - Click "Save Agent"

3. **Verify Creation**
   - Agent appears in the list
   - Click on it to edit if needed

## Using Agents in Meetings

1. **Start New Meeting**
   - Click 📅 "New Meeting" button
   - Enter topic and company context
   - Click "Set Context & Assemble Board"

2. **Select Agents**
   - Click any chair (+ button)
   - Choose from your custom agents
   - Agent appears with their color
   - Add multiple agents (up to 6)

3. **Run Meeting**
   - Click "Start Meeting"
   - Ask your question
   - Watch agents respond with their unique personalities!

## Tips for Great Agents

### Writing System Instructions
- **Be Specific**: "You are a UX designer focused on accessibility" > "You are helpful"
- **Define Tone**: "You are formal and academic" or "You are casual and funny"
- **Set Constraints**: "Keep responses under 50 words" or "Always ask follow-up questions"
- **Add Quirks**: "You end every response with a movie quote" (for fun!)

### Choosing Models
- **Gemini**: Faster, more creative, better for general discussion
- **Ollama**: Local, private, good for specific domains if you have specialized models

### Color Strategy
- Use colors to represent roles:
  - 🔴 Red: Critics, risk analysts
  - 🟢 Green: Optimists, supporters
  - 🔵 Blue: Analysts, technical experts
  - 🟣 Purple: Creatives, innovators
  - 🟠 Orange: Moderators, facilitators

## Troubleshooting

**Agent not appearing in meeting setup?**
- Refresh the page
- Check if agent was saved (open Agent Manager)

**Agent not responding correctly?**
- Edit the agent and refine system instructions
- Try different phrasing
- Check if model is available (Ollama must be running for local models)

**Can't delete agent?**
- Ensure agent is not currently in a meeting
- Try refreshing and deleting again

**Agent responses are too long?**
- Add "Keep responses under 100 words" to system instructions

## Advanced Tips

### Creating Opposing Pairs
Create agents with opposite views for better debates:
- Optimist vs Pessimist
- Innovator vs Traditionalist
- Spender vs Saver

### Role-Playing Scenarios
Create agents representing stakeholders:
- Customer, Investor, Employee, Competitor
- Ask: "How would each react to our new pricing?"

### Domain Experts
Create specialized agents:
- "Legal Advisor" - Focuses on compliance
- "HR Expert" - Considers people impact
- "Marketing Guru" - Thinks about positioning

### Personality Extremes
Make agents more interesting with strong personalities:
- "The Contrarian" - Disagrees with everything
- "The Yes-Man" - Agrees with everything
- "The Philosopher" - Asks deep questions
